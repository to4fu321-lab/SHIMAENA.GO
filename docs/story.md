# 本人のストーリー（発表用のインタビュー記録）

> 11/6〜 インタビュー形式で本人から聞き取ったもの。発表（デモ動画・提出文）の「想い」の素材。本人のことばをなるべくそのまま残す。

## 第1回: 原点

### 雪かきと自分
- 埼玉から札幌へ、15年前に移住。日本一周をして、北海道の自然の美しさ・食の美味しさ・街の美しさ・人の優しさに惚れた。
- 雪かきは本当に大変。毎年腰を痛める。時間もかかる。「毎日、庭に何メートルも穴を掘っているようなもの」。
- 北海道では、車がスタックすると見ず知らずの周りのみんなが助ける。100%。牽引ロープで引っ張ったり、スコップを持ってきて雪を掘ったり。自分も何回も助けたり、助けられたりしている。
- 雪かきも、隣の駐車場の人が手伝ってくれたことがある。**でも雪かきは「隣の部屋の人」「駐車場が隣の人」までの範囲。知らない人の家の雪かきはしない。**
  → スタックは「困っている人が目の前にいる」から助ける。雪かきは「誰がどこで困っているか見えない」から助けられない。シマエナGO はここを見えるようにする。

### なぜ「ひとり」「つながり」なのか
- 人は誰しも高齢者になる。見守りなどは、近い未来にテクノロジーが解決すると思う。
- この広い世界で、人生で人と出会う・会話する・仲良くなる・一緒になるのは、天文学的な確率。だから、その確率に少しでも関わりたい。
- **190万人いて、毎日同じ電車に乗っているのに、一生話さない人が 99%。そこを変えていきたい。**
- 自分も人と仲良くなるのは得意ではない。でも、誰かの何かのきっかけになって、その人の人生が面白くなったらうれしい。

### 使ってほしい人
- 日々を、ただただ過ごしている人。それでも素晴らしい人生だけど、**自分の行動で世の中がほんの少し良くなる・変わることを、経験してほしい。**
