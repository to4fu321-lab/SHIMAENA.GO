# LINE で1タップ開始の設定（本人がする作業・5分）

どの「LINE で参加」ボタンも、LINE アプリの中の画面 `/start` を開きます。
最初の1回だけ「許可する」を押すと、**本人の確認と友だち追加が同時に**終わるようにするための設定です。

## 1. LIFF アプリの設定（LINE Developers）
1. https://developers.line.biz/console/ を開き、シマエナGO の **LINE ログイン チャネル**（LIFF アプリがあるほう）を選ぶ
2. 「LIFF」タブ → シマエナGO の LIFF アプリ → 「編集」
3. 次のようにして保存する
   - **エンドポイント URL**: `https://yukikaki-karano-kaihou.vercel.app`（最後に `/` や `/map` を付けない）
   - **Scope**: `profile` と `openid` にチェック（`chat_message.write` は今のままでよい）
   - **友だち追加オプション**: **On (Aggressive)** ← いちばん大事。これで「許可する」と同時に友だち追加になる
   - **サイズ**: Full

## 2. LINE ログイン チャネルと公式アカウントを結ぶ
1. 同じ LINE ログイン チャネルの「チャネル基本設定」
2. **リンクされた LINE 公式アカウント** で「シマエナGO」（Messaging API のアカウント）を選んで保存
   - 同じプロバイダーの中にあるアカウントだけ選べる

## 3. 確かめる
- スマホの LINE で、自分あてに `https://liff.line.me/2012345231-Qkw9f5vb/start` を送って押す
- 「許可する」の画面に「友だち追加」のチェックが出れば OK（もう友だちならそのまま登録済みの人はソロ出動へ）

## うまくいかないとき
- Safari で開いたときは「LINE アプリで始める」を押すと LINE アプリに切り替わる
- 「400 Bad Request」が出る → 1 の **エンドポイント URL** が今の公開 URL と違っていないか確かめる
