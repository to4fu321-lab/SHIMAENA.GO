# デモ動画の台本（3分・日本語）— 11/6 版

## 発表の芯
**雪かきは入口。目的は「ひとり」をなくすこと。**

- 雪かきで亡くなる人の約3分の2は65歳以上。死亡事故の約8割は **ひとりで作業していたとき**（内閣府）。
- ひとりで暮らす高齢者は、近所の人に「手伝って」と頼みにくい。
- 若い人も町に知り合いがいない。近所の人と会う理由がない。
- 事故も孤独も、根っこは同じ **「ひとり」**。だから **「寒い冬は、くっついて乗り切る。」**
- シマエナGO は、雪かきを「ひとりの作業」から「チームの朝」に変える。顔を合わせて、「ありがとう」が行き交う。チームが毎週入れ替わるので、知り合いが増えていく。
- めざす先: 雪国の冬を「こもる季節」から「人が出会う季節」に。高齢者も若者も、地域に居場所がある町（ウェルビーイング）。

言い方の注意: まだ実際の町では使っていないので、「孤独を解決した」とは言わない。「会う理由をつくる」「つながりのきっかけ」と言う。

## うまくいかないときの逃げ道
- 通知が届かない → 隊長トーク（`/chat`）を開けば同じ知らせが並んでいる。`/map?as=h1` のように架空の人の画面でも同じ流れを見せられる。
- 写真の確認で「まだ」と言われる → 玄関前から道路側を明るく撮る。判断できない写真は「報告として受け付け」になる。どうしてもなら「それでも完了にする」。
- 合流にならない → `/admin` の **5 駆けつけ** は手の空いた架空の人を別チームから入れる。
- 途中でやり直したい → **0 前夜の予告** で朝をまっさらに（カードは残る）。

## 提出文（プロジェクト概要）
> **シマエナGO** — 寒い冬は、くっついて乗り切る。
>
> 雪かき中の事故で亡くなる人の約3分の2は65歳以上で、死亡事故の約8割はひとりで作業していたときに起きています（内閣府）。ひとりで暮らす高齢者は近所に頼みにくく、若い人も町に知り合いがいません。事故も孤独も、根っこは同じ「ひとり」です。
>
> シマエナGO は、雪かきを入口に、町の人が顔を合わせる理由をつくるアプリです。雪かきをお願いしたい家は一度登録するだけ。10cm 積もった朝は自動で近所に届き、Claude の「隊長」が家ごとに人数と担当を決めて、町内のランダム3チームに10分単位の仕事として割り振ります。地図がチーム色に塗られていき、写真1枚で完了すると Claude が確かめ、家の人は「ありがとう」を1タップで返せます。動いた人にはその時だけのカードが届き、離れて暮らす家族にも完了が知らされます。チームは毎週入れ替わるので、知らなかった近所の人と知り合いになれます。仲間がいない日もソロの見回りで参加できます。
>
> めざすのは、雪国の冬を「こもる季節」から「人が出会う季節」に変えること。高齢者も若者も、地域に居場所がある町です。雪かきの知識がないプログラミング初心者が、スマホから Claude Code に指示するだけで6日間で作りました。
