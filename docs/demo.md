## うまくいかないときの逃げ道
- LINE が届かない → `/admin` の「記録」に「LINE で N 人に送信」と出ているか。0 人なら登録（line_user_id）が入っていない。`/map?as=h1` のように架空の人の画面でも同じ流れを見せられる。
- 写真の確認で「まだ」と言われる → 玄関前から道路側を明るく。`/map` の「終わりました」からでも送れる。
- 混成にならない → `/admin` の **5 駆けつけ** は手の空いた架空の人を別チームから入れる。
- 途中でやり直したい → **0 前夜の予告を出す** で朝をまっさらに（カードは残る）。

> **シマエナGO** — 寒い冬は、くっついて乗り切る。
> 札幌の一軒家にひとりで暮らす高齢者は、雪の朝、玄関から道路まで出られないことがあります。シマエナGO は、雪の予報が出た夜に LINE で予告し、朝 6:30 に1問だけの点呼を送ります。「いいえ」の1タップで、Claude が司令官として家ごとの重要度と必要人数を決め、町内のランダム3チームに5分単位の小さな仕事として割り振ります。地図の 50m マスがチーム色に塗られていき、写真1枚で完了すると Claude が確認し、動いた人にはその朝だけの「ありがとうカード」（Claude が名前をつけ、SVG で描く）が届きます。人手が足りない家は 300m → 600m → 1km と近所に声をかけ、返事がない家は家族と近所に知らせます。お金ではなくチーム戦と毎朝の小さな達成で、町内の助け合いを続く仕組みにします。プログラミング初心者がスマホから Claude Code に指示するだけで、6日間で作りました。
