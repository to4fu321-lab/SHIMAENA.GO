# デモ動画の台本（3分・日本語）— 11/6 版（本人のストーリー入り）

## 発表の芯
**雪かきは入口。目的は「ひとり」をなくすこと。**

- 札幌は人口約193万人の大都市なのに、年に6mを超える雪が降る年がある。
- 65歳以上の5人に1人がひとり暮らし（2020年国勢調査）。札幌の高齢単身世帯は 12.6% → 2040年に 18.7%、ほぼ5世帯に1世帯。
- 日本の高齢者は近所付き合いがない人が 17.4%（米国の2倍、ドイツの3倍）。困ったとき近所の人を頼れるのは 12.9%（令和8年版高齢社会白書）。だから「手伝って」と頼めない。
- 「しばしば孤独」な人は、70代（2.5%）より 20〜30代（5.5〜6.1%）のほうが2倍以上多い（内閣府 令和7年）。若い人も町に知り合いがいない。町内会は担い手が足りない。
- 北海道の高齢者は冬に出かける範囲が狭まり、積雪期は「除雪」と「地域での役割」が外に出る楽しみにつながる（杉田ほか 2024・原田・村松 2020）。**雪かきは、冬に外へ出る理由になる。**
- 根っこは同じ **「ひとり」**。だから **「寒い冬は、くっついて乗り切る。」**
- シマエナGO は、雪かきを「ひとりの作業」から「チームの朝」に変える。顔を合わせて、「ありがとう」が行き交う。チームが毎週入れ替わるので、知り合いが増えていく。
- めざす先: 雪国の冬を「こもる季節」から「人が出会う季節」に。高齢者も若者も、地域に居場所がある町（ウェルビーイング）。

言い方の注意:
- まだ実際の町では使っていないので、「孤独を解決した」とは言わない。「会う理由をつくる」「つながりのきっかけ」と言う。
- 雪かきの事故の数字は使わない（事故の多くは屋根からの転落で、このアプリの玄関前の雪かきとは別の話のため）。

## Claude の使い方（発表で話すこと）
審査の 25% が「Claude の活用」。**「AI に任せる所」と「任せない所」を決めて使った**ことを、画面と1枚の図で見せる。

**1. アプリの中の Claude は、町の「隊長」**（人と人をつなぐ所だけに使う）
- **割り振る**: 司令官。家ごとの人数・担当・理由を決める（`lib/claude/commander.ts`）。
- **確かめる**: 写真1枚で、雪がどけられて通れるかを確かめる（`photo.ts`）。頼むときは写真から「玄関前／車庫前／道路まで」を読む（`area.ts`）。
- **つなぐことば**: 隊長トークの相談で、その人が求めているもの（つながり・運動・地域貢献・ゲーム）を読み取って合う参加の仕方をすすめる（`concierge.ts`）。カードの名前と、今日の話題から描く挿絵（`card.ts`）、誘いの文（`invite.ts`）。

**2. AI に任せない所**
- 得点・どけた雪の kg・夜かどうか・安全の注意は、ふつうのプログラムが決める。Claude には計算した数字だけを渡し、返ってきた答えはプログラムが点検する。
- **「ありがとう」は AI に書かせない。** 家の人が押して、声で残す（本人の考え: 感情を乗せるところは人が。`docs/story.md`）。
- 体調や医療は判断しない。名前や場所は文から外す。
- 毎回、同じ採点表（`data/rubric.json`）を渡して、答えの基準をそろえる。答えはすべて JSON。
- 重い判断（司令官・写真）は Opus、短い文は Haiku と使い分ける。鍵がないときも、同じ形の仮の答えで最後まで動く。

**3. みんなの知恵をくみ取る**（作者に雪かきの知識がないのを AI で補う）
- **今朝の先生**: 頼む家の高齢者が教えてくれた雪かきのコツから、今朝の雪に合うものを Claude が1つ選んで手伝う人に届ける。高齢者が「助けられる側」だけでなく「教える側」になる。
- **声を貯めて改善**: 隊長への相談から「求められていること」を貯め、1週間ごとに改善の提案を出す。採用は人が決める。

**4. Claude Code で作った**
- プログラミング初心者が、スマホの Claude アプリから日本語で指示するだけで6日で作った。
- 仕様を先に決め（`docs/spec.md`）、`CLAUDE.md` に手順を書いて、ループで1タスクずつ自走させた（確認 → スクショ → コミット → 記録）。
- 企画役のエージェントに、事例や数字を調べさせた（`docs/ideas/`）。
- 性格を決めた架空の参加者20人と頼む家10軒で、本物の処理（司令官・写真の確認・カード）を通して町の朝を丸ごとテストした（`npm run sim`）。

## うまくいかないときの逃げ道
- 通知が届かない → 隊長トーク（`/chat`）を開けば同じ知らせが並んでいる。`/map?as=h1` のように架空の人の画面でも同じ流れを見せられる。
- 写真の確認で「まだ」と言われる → 玄関前から道路側を明るく撮る。判断できない写真は「報告として受け付け」になる。どうしてもなら「それでも完了にする」。
- 合流にならない → `/admin` の **5 駆けつけ** は手の空いた架空の人を別チームから入れる。
- 途中でやり直したい → **0 前夜の予告** で朝をまっさらに（カードは残る）。

## 提出文（プロジェクト概要）
> **シマエナGO** — 寒い冬は、くっついて乗り切る。
>
> 65歳以上の5人に1人がひとり暮らし。日本の高齢者は近所付き合いがない人が 17.4% と米国の2倍で、困ったとき近所を頼れるのは 12.9% にすぎません。雪の朝、玄関から出られなくても「手伝って」と頼めない。一方で「しばしば孤独」な人は 70代より 20〜30代のほうが2倍以上多く、若い人も町に知り合いがいません。根っこは同じ「ひとり」です。シマエナGO は、雪かきを入口に、町の人が顔を合わせる理由をつくるアプリです。
>
> 雪かきをお願いしたい家は一度登録するだけ。10cm 積もった朝は自動で近所に届き、エリアのランダム3チームが10分単位の仕事として向かいます。写真1枚で完了すると、家の人は「ありがとう」を1タップで返せます。動いた人にはその時だけのカードが届き、離れて暮らす家族にも完了が知らされます。チームは毎週入れ替わるので、知らなかった近所の人と知り合いになれます。
>
> Claude は町の「隊長」です。家ごとの人数と担当を決め、写真で完了を確かめ、相談にのって一人ひとりに合う参加の仕方をすすめます。得点や安全の判断はプログラムが受け持ちます。そして「ありがとう」は AI に書かせず、家の人の声で手伝った人に届けます。気持ちを伝えるところは、人がやるべきだと考えたからです。高齢者が教えてくれた雪かきのコツは「今朝の先生」として手伝う人に届きます。
>
> めざすのは、雪国の冬を「こもる季節」から「人が出会う季節」に変えること。作ったのは、15年前に埼玉から札幌へ移ってきた学生服メーカーの営業です。子どもたちに「やってみよう」と話している自分が、40代でやってみました。プログラミング初心者が、スマホから Claude Code に指示するだけで6日間で作りました。
