# 紹介動画 v3（3分）— 構成・カット割・音楽・作り直し方

`docs/video/shimaena-go-3min.mp4`（1920×1080・30fps・**2分58秒**）。11/10 に、審査基準の4項目に合わせて作り直した版です。
動く画面は**本物のアプリ**（本番ビルドの録画）、音楽と効果音は**アプリと同じ楽器**（Web Audio 合成・音ファイルなし）、絵と図は全部プログラムで描いています。

> **先に知っておいてほしいこと（正直に）**
> 1. **ナレーションは合成音声です**（仮の声）。11/8 に本人が決めた「ナレーションは全部本人の声」に戻すときは、下の「本人の声に差し替える」で、**1行ずつ録って置くだけ**で入れ替わります。
> 2. **声のありがとうの声も合成です。** 画面の下に「※ この動画の声は合成音声です」と出しています。娘さんの声に差し替えたら、注を消します（`voices.cjs` の `voiceNote` を `""` に）。
> 3. **画面の録画は、Claude の鍵なしで撮っています。** だから隊長の理由の文・写真の確認・カードの絵は「見本の答え」（鍵がないときにアプリが出す定型）です。**流れと画面は本物**ですが、**カードの絵は Claude が描いたものではありません。** 鍵を入れて撮り直せば本物になります（下の「Claude の本物の答えで撮り直す」）。提出や公開の前に、ここだけは撮り直すのをおすすめします。
> 4. 実写は本人の写真2枚（初雪の通り・公園）だけ。車を押す場面・雪かきの前後・未来の朝は絵と画像で、画面に「※イメージ」と出しています。

## 魅せ方で決めたこと

- **冒頭5秒で「何のアプリか」。** 物語（札幌15年）から入りますが、同じ画面の右上に「雪の朝、ひとり暮らしの家の雪かきを、近所の3チームが10分だけ手伝うアプリ」を出します。
- **笑いは1つ、泣きは1つ。** 笑いは「100%」。泣きは声のありがとう。その前後は詰め込みません。
- **山場は音を引く。** 「ここだけは、AIに書かせません」で音楽を消し、声だけにします。3分の中でいちばん静かな10秒が、いちばん残ります。
- **スマホの中は本物、外で説明する。** 小さくて読めない所は、同じ画面をその場で拡大して横に出します（隊長の理由・地図・カード）。押した所には指の印と波紋。
- **Claude の話は「証拠」で。** 本人が送った指示の文（`docs/devlog.md`）、コミットの記録（`git log`）、サブエージェントの設定（`.claude/agents/kikaku.md` の `model: fable`・`effort: max`）を、そのまま画面に出します。
- **字幕は、画面の大きな文字と同じときは出さない。** 同じ文が2つ並ぶと安っぽく見えるためです（冒頭・一行・ありがとう・締め）。
- **言いすぎない。** 「孤独を解決した」とは言わず、「この冬、まず一つの町内で」「まだ本物の町では使っていません」と画面に書きます。

## 音楽: アプリの3曲を、3分に並べ直した

新しい曲は作っていません。**アプリの中で鳴っている曲と楽器**（`lib/sound/`）を、ヘッドレスのブラウザで書き出して並べました（`scripts/video-v3/score.cjs`）。
アプリと同じ場面で同じ曲が鳴ります: 朝の画面は「しらかばの朝」、**「行く」を押した瞬間に「出撃！」**、**完了の瞬間に「灯りがともる」**。

効果音もアプリのものです（タップ・ポロン・シュッ→ピンポンパン・カシャッ・完了のファンファーレ・カードの「キラ〜ン」「ドンッ」）。**アプリが鳴らすのと同じ瞬間**に置いています（`scripts/video-v3/edit.js`）。
声が鳴っている間は音楽が自動で下がり、全体は -14 LUFS（ネット動画の標準）にそろえています。

## 作り直す

```bash
npm install && npm run build
node scripts/video-v3/make.cjs            # 時間割 → 音楽 → 全コマ → 音 → MP4（約7分）
node scripts/video-v3/make.cjs record     # アプリの画面も録り直す（＋3分）
node scripts/video-v3/make.cjs audio      # 画はそのまま、音だけ入れ替える
```

| 直したいもの | 直すファイル |
|---|---|
| ナレーションの文・場面の順番・間 | `scripts/video-v3/script.cjs`（秒は書かない。声の長さから自動で時間割になる。180秒を超えると止まる） |
| 場面の絵・文字 | `scripts/video-v3/compose-s1.js`〜`s4.js`（章ごと）。確かめるのは `node scripts/video-v3/render.cjs preview 12.5,40`（その秒の絵が `.video/v3/preview/` に出る） |
| どの録画をどこに置くか・効果音 | `scripts/video-v3/edit.js` |
| 音楽の並び | `scripts/video-v3/score.cjs`（楽器は `audio/entry.ts`） |
| 声（合成）の種類・速さ・最後のクレジット | `scripts/video-v3/voices.cjs` |

### 本人の声に差し替える（おすすめ）

1. `scripts/video-v3/script.cjs` の `text` を、静かな部屋で**1行ずつ**録ります（`n01`〜`n48`。スマホのボイスメモでよい）。
2. `.video/v3/own/n01.m4a` のように、行の番号の名前で置きます（wav・m4a・mp3）。全部でなくても、録った行だけ入れ替わります。
3. `node scripts/video-v3/narrate.cjs` → `node scripts/video-v3/make.cjs`。長さは自動で測り直します（3分を超えたら `script.cjs` の `tail` を縮めるか、文を短く）。
4. 声のありがとう（`d01`）を娘さんの声にしたら、`voices.cjs` の `voiceNote` を `""` に、`credits` も直します。

### Claude の本物の答えで撮り直す

`.env.local` に `ANTHROPIC_API_KEY` を入れて `npm run build` → `node scripts/video-v3/make.cjs record`。
隊長の理由・写真の確認・カードの絵が本物になります（Claude を待つぶん、録画は少し長くなります。場面の長さは `edit.js` が印から合わせ直します）。

### 仮の声を作り直す

`scripts/video-v3/tts/README.md`（手元で動く合成音声。読み間違いの直し方もここ）。
