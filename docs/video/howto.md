動く画面は本物のアプリ（本番ビルド）を録画したもの。ナレーションは**仮の声**（Google 翻訳の読み上げ）で、

## 自分で作り直す手順（パソコン1台・15分）

```
npm install
npm run build
python3 -m pip install gTTS
python3 scripts/demo-video/narration.py .video/narration   # 仮の声（本人の声に差し替えるときは下）
faketime -f '+4h' node scripts/demo-video/record.cjs        # 画面を録画（朝 6〜19 時なら faketime は不要）
git log --format=%s | grep -v '^Merge' | head -48 > .video/commits.txt
node scripts/demo-video/compose.cjs all                      # コマ出し → 合成 → 音 → docs/video/demo3min-v2.mp4
```

- `faketime` は Ubuntu なら `sudo apt install faketime`。夜（日本時間 19〜6 時）は防犯のルールで「行く」が断られるので、時計を朝にずらして録画します。
- Claude の鍵（`ANTHROPIC_API_KEY`）がないときは仮の答え（定型文）で動きます。鍵を入れて録画すると、隊長の文・写真の確認・カードの名前が本物になります。
- 動く画面だけ撮り直したいときは `record.cjs` → `compose.cjs all`。テロップや秒数を直したいときは `timeline.cjs` を直して `compose.cjs all`。

## 本人の声に差し替える（提出前にやること）

1. `scripts/demo-video/narration.py` の `LINES` が台本です。静かな部屋で、スマホのボイスメモで**1行ずつ**録ります（行の間は止めてよい）。
2. 録った音声を `n01.wav` … `n16.wav` の名前で `.video/narration/` に入れます（mp3 でもよい: `ffmpeg -i 録音.m4a .video/narration/n01.wav`）。
   - 隊長の声（`c01`・`c02`）と娘さん役（`d01`）はそのままでもよいし、娘さんに本当に吹き込んでもらうなら `d01.wav` を差し替えます。
3. `narration.py` を**動かさずに**、`.video/narration/narration.json` の `seconds` をそれぞれの長さに直します（`ffprobe -i n01.wav` で秒がわかる）。
4. 1行が長くなったら、`scripts/demo-video/timeline.cjs` のその場面の `end` と、次の場面以降の `start`/`end` を同じ秒数だけ後ろにずらします。合計は **180 秒以内**に。
5. 秒数を変えていなければ `node scripts/demo-video/compose.cjs reaudio`（画はそのまま、音だけ入れ替える・1分）。秒数を変えたら `node scripts/demo-video/compose.cjs all`（全部作り直す・10分）。

## 実写に差し替える（任意）

イラストの3場面（0:00 雪かき・0:13 ソファー・2:38 未来）は、本人の実写（顔なし: 手元・足元・後ろ姿）に差し替えると強くなります。
動画編集アプリ（iPhone なら iMovie）で `demo3min-v2.mp4` を読み込み、その秒だけ上に実写を重ねるのがいちばん簡単です（音はそのまま残す）。

## イラストの人物

`scripts/demo-video/compose.html` の `person()` が人物を描きます（帽子・髪・マフラー・ミトン・顔。ポーズは shovel／back／cane／blower／wave／cup、kind は adult／child／elder）。
色や並びを変えたいときは、`snow()`（冒頭）と `future()`（未来の朝）の `person({...})` の行を直して `compose.cjs preview 3,160` で確かめます。
操作画面のタップ位置は `record.cjs` が記録し、合成で指と波紋を出します。

## 音楽

`docs/video/bgm.mp3`（`scripts/make-music.py` でプログラムだけで作った 3 分の曲。0〜1分 静か／1〜2分 にぎやか／2〜2:40 あたたか／最後 ゆかい）。
ナレーションの間は自動で小さくなり、**声のありがとうの場面（1:29〜1:51）は無音**、最後はフェードアウトします。
最後に全体の音量をネット動画の標準（-14 LUFS）にそろえます（11/8 本人「音が出ない」→ 前は -19 LUFS で、スマホのスピーカーでは小さすぎた）。
