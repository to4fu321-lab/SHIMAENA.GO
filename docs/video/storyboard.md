## 動画の約束
- 3分以内。**7割はアプリの操作画面**（約125秒）。残り3割は雪かきの実写・3羽・ソファー・将来の理想。
- **全部スマホだけで作った**。パソコンは「この発表動画の編集」にしか使っていない。
- 言わないこと: 「孤独を解決した」（まだ町で使っていない）。雪かき事故の数字。実在の名前・住所。
- 自治体・企業との連携は**「これからやりたいこと」として言う**（まだ決まった連携はない。「連携しています」とは言わない）。

- **テロップ**: 「ありがとうは、本人の声で」「離れて暮らす孫から」
- **⚠ 今のアプリとのちがい（大事）**: 今のアプリで「声のありがとう」を吹き込めるのは**家の人（拠点の持ち主）だけ**。「家族の代わりに登録」した家族は、家の登録はできるが、参加者にはならないので、家族の画面からは吹き込めない（`lib/morning/ops.ts` の `voiceThanksTarget`）。選べる道は2つ:

  - **道2（直してから撮る）**: 連携コードで紐づいた家族も、その家の雪かきに声のありがとうを吹き込めるようにする。仕様の変更なので本人の了承が要る（`docs/devlog.md` に提案として書いた）。了承があれば撮影の前に入れられる大きさ。

## ⑤ 何を頼む場面か（2:18 のカット）
「スマホだけで作った」を見せるために、**スマホの Claude アプリで Claude Code に日本語で頼んでいる画面**を数秒映す。撮り方は2つ。

**決定: 案A。**

- **案A（決定）: 今までの会話をスクロールする。** スマホの Claude アプリで、これまでのセッション（例: 「ホームの隊長を3羽にして」「隊長の声をシマエナガっぽい声に」）を開いて、指示と「できました」の返事を親指でスクロールする画面を収録。新しく何かを変える必要がないので、撮影の日に失敗しない。続けて、そのとき変わったホームの3羽を映す。
- **案B（ライブ感）: 撮影中に、小さな変更を1つ頼む。** 例: 「ホームの隊長の吹き出しを『動画を撮ってるしま！』にして」→ 返事 → 公開版に反映されたホームを映す（反映まで数分かかるので、待ち時間はカット）。撮ったあとで元に戻すのを忘れない。

どちらも、画面に**API キーや個人のメールアドレスが写らないか**確かめてから使う。

## 自治体・企業との連携の言い方（調べたこと）
- **札幌市の福祉除雪**: 札幌市社会福祉協議会が実施。高齢者や障がいのある人の世帯で、玄関先から道路までの雪を「地域協力員」が除雪する。毎冬、個人・企業・団体の協力員を募集している。町内会の関係者からは、利用が増えるので**協力員の確保が今後も大事な課題**という声。
- **国の認識**: 国土交通省は、豪雪地帯で人口減少と高齢化により**雪処理の担い手が減っている**として、町内会などの共助除雪や除雪ボランティアの受け入れを後押ししている。
- **地域協力員の募集（札幌市）**: 正式な名前は「地域協力員」（「地域協力隊」ではない）。近所の申込世帯を担当し、道路除雪の日の正午ごろまでに1日1回、出入口（幅1.5m くらい）と玄関までの通路（80cm くらい）を除雪する。期間は 12月1日〜3月20日。1シーズン通して協力すると1世帯 23,000円の活動費。個人・ボランティア団体・NPO・福祉施設・学校・企業、だれでも参加できる。令和6年度は 3,721人が協力。募集のページには人手不足の記述はない → 「足りない」は町内会の関係者の声（屯田）として言う。
- **アルカサル（札幌健康アプリ）**: 札幌市が 2026年4月から本格運用。40歳以上の市民が対象で、歩くことなど健康づくりでポイントが貯まり、電子マネーへの交換や抽選に使える（条件あり）。「健康・経済好循環モデル実証事業」として、イオン北海道・大塚製薬・北海道コカ・コーラボトリング・SHARE と覚書を結び、協賛企業も募集している。アプリからイベントやボランティア活動も探せる。
  - → 動画で言えること: 「アルカサルのように、企業と組んで、ポイントを地元の商品やサービスに」。**名前は出してよい（11/7 本人）。**「アルカサルと連携しています」とは言わない（決まっていないため）。
- **仕様とのちがい（大事）**: 今の仕様は「得点はお金に換えない」「決済はしない」（`docs/spec.md` 5章・12章）。アプリの「ご褒美（想定）」も「地元の銭湯やお店と町内会がつながる想定。お金には換えません」と書いている。だから動画では**「これからの構想」**として言い、アプリはこのまま。実装するなら仕様の変更になるので、`docs/devlog.md` に提案として書いた。
