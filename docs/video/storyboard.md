# 発表動画のたたき台（3分・日本語）— 11/8 撮影用

> 11/7 に、今の実装・README・`docs/demo.md`・インタビュー（`docs/story.md`）を読み直して作った**たたき台**。本人が「ここは違う」「もっとこう」と直す前提。決まったら `docs/demo.md` の表を差し替える。

## 動画の約束（本人の希望）
- 3分以内。**7割はアプリの操作画面**（約125秒）。残り3割（約55秒）は雪のシーン・3羽の写真・将来の理想のイメージ画。
- **全部スマホだけで作った**ことを伝える。パソコンは「この発表動画の編集」にしか使っていない。
- 笑いを入れる。「社会問題を解決したい」と大きく振って、「思い立ったのはソファーで寝っ転がってスマホをいじっていた時」で落とす。ただし本気の部分（ありがとうの声・見たい未来）は笑わせない。
- 言わないこと: 「孤独を解決した」（まだ町で使っていない）。雪かき事故の数字。実在の名前・住所。

## 一言で（動画の芯）
**雪かきは入口。目的は、町から「ひとり」をなくすこと。**
笑いの芯: **真面目な社会課題を、いちばんダラダラした姿勢で解決しにいった人の話。**

## シーンごとの台本

ナレーションは本人の声。「」の中は本人のことば（`docs/story.md`）をなるべくそのまま。テロップは短く。

### 0:00 イメージ① 札幌の静かな朝（15秒）
- **映す**: 雪の朝の通り。できれば、ひとりで黙々と雪かきをしている人（後ろ姿・遠景）。実写が撮れなければ雪の写真を2〜3枚ゆっくり。
- **ナレ**: 「札幌の冬の朝は、静かです。みんな、ひとりで雪かきをしている。」「車がスタックしたら、北海道の人は100%助ける。でも、知らない家の雪かきはしない。誰が困っているか、見えないからです。」
- **テロップ**: 「65歳以上の5人に1人が ひとり暮らし」「困ったとき近所を頼れる人 8人に1人」
- **最後の2秒**: 3羽のシマエナガが枝で身を寄せ合う写真（※下の「素材の注意」）。

### 0:15 笑い①＋タイトル（15秒）
- **映す**: 実写。ぬくぬくのソファーに寝っ転がった本人の手元。ブランケット、スマホ、湯気の立つ飲み物。顔は映さなくてよい（足とスマホだけで伝わる）。
- **ナレ**: 「この問題を、なんとかしたい。そう思い立ったのは……**ソファーの上でした。**」（間）「雪かきで毎年腰を痛めているので、寝っ転がって考えました。」
- **テロップ**: 「開発環境：ソファー」「使った道具：スマホ1台」
- **タイトル**: 「シマエナGO ― 寒い冬は、くっついて乗り切る。」（アプリの BGM を小さく）
- 案: ここで隊長の声（VOICEVOX）に「シマエナ隊長だしま！」と一言だけ言わせると、キャラが先に立つ。

### 0:30 アプリ① ホーム（10秒）
- **映す**: `/?as=h1`。空と雪、枝に3羽（隊長＋仲間2羽・マフラーが3チームの色）、隊長の吹き出し、「あと4軒で完了！」、大きな「雪かきGO！」。
- **ナレ**: 「シマエナGO は、雪かきを『ひとりの作業』から『チームの朝』に変えるアプリです。町内を3つのチームに分けて、毎週シャッフルします。」
- **テロップ**: 「3チーム・毎週シャッフル・個人順位なし」

### 0:40 アプリ② お願いする家は1回だけ登録（10秒）
- **映す**: `/ask`。「おまかせ」「玄関前」を絵つきの大きなボタンで押す。写真を撮ると Claude が「どこまで」を読む（写真は保存しない）。
- **ナレ**: 「雪かきをお願いしたい家は、冬の初めに一度だけ登録。**雪の朝に『手伝って』と頼む必要はありません。** 頼みにくさを、仕組みで消しました。」
- **テロップ**: 「頼まなくていい」

### 0:50 アプリ③ 雪の朝 6:30、隊長が割り振る（15秒）
- **映す**: `/admin` の「0 前夜の予告 → 1 → 3」を押す（2 は押さない）。A（田中さん役）の隊長トークに「おはよう」「助けてほしい家があります」が届く。地図の「シマエナ隊長から」に Claude の理由1行をアップ。
- **ナレ**: 「10cm 積もった朝、登録した家の雪かきが自動で近所に届きます。Claude の隊長が、家ごとに人数と担当と理由を決めます。」
- **テロップ**: 「Claude が割り振り」「家の人は何もしなくていい」
- 小ネタ（任意）: 前夜の予告の「今朝の雪の名前」（例『もっちり大福』）を1秒見せる。

### 1:05 アプリ④ 地図で「行く」（12秒）
- **映す**: `/map?as=h1`。50m マスの白い町。赤く点滅する家（人手不足）。「行く（10分でも）」を押す → マスがチーム色に。B（別チーム）も「行く」→ 2色に。
- **ナレ**: 「知らない人の家でも、チームなら行ける。10分でもいい。」
- **テロップ**: 「10分だけ助けに行く」

### 1:17 アプリ⑤ 写真1枚で完了 → カード（15秒）
- **映す**: 玄関前で写真を撮る手元（実写、2秒）→ 「終わりました（写真）」→ Claude の確認の文（通れる・凍っていない）→ MISSION CLEAR → その時だけのカード（表と裏、No.001）。
- **ナレ**: 「写真1枚で、Claude が『通れるか・凍っていないか』を確かめます。得点が入って、その時だけのカードが届く。離れて暮らす家族にも『終わりました』が届きます。」
- **テロップ**: 「Claude が写真を確認」「家族にも届く」

### 1:32 アプリ⑥ いちばんの見せ場：声のありがとう（23秒）
- **映す**: C（小林さん役）の隊長トーク「終わりました。ひとこと返しませんか」→ 「🎤 声でありがとう」→ 吹き込む（家族か知人の声、10秒）→ A のトークに「▶ 声のありがとう」→ 再生。**ここは BGM を止めて、声だけ**。
- **ナレ**: 「ありがとうは、AI に書かせません。文字にもしません。」「気持ちを伝えるところは、人の声で。」（声が流れるあいだはナレーションなし）
- **テロップ**: 「ありがとうは、本人の声で」
- 本人のことば（第2回）をここに置く案: 「AI は本当に楽です。でも、感情を乗せるところまで任せたら、自分がいなくなる気がした。」

### 1:55 アプリ⑦ 隊長トーク：相談・かわいい声・5か国語（12秒）
- **映す**: `/chat?as=h1`。「近所の人と知り合いたい」と送る → 隊長の返事（Claude が町の様子を自分で調べて答える）→ 🔊 で隊長の声（VOICEVOX 雨晴はう）が読む → 🌐 で English に切り替わる。
- **ナレ**: 「相談は隊長に。その人が求めているもの、つながりか、運動か、地域貢献か、ゲームか、を読んで参加の仕方をすすめます。」
- **笑い（軽く）**: 隊長の語尾「〜しま」「〜えな」が聞こえたところで、テロップ「※語尾はシマエナガです」。
- **テロップ**: 「Claude が相談にのる」「日本語／English／中文／한국어／Tiếng Việt」

### 2:07 アプリ⑧ 高齢者が「教える側」になる（8秒）
- **映す**: 今朝の先生（手伝う人に届く25字のコツ）→ `/kikigaki`（雪の思い出を隊長が聞く）→ `/book`（町の週刊絵本を横にめくる）。各2〜3秒。
- **ナレ**: 「高齢者は、助けられる側だけじゃない。雪かきのコツを教える側に。雪の思い出は、町の絵本の1ページになります。」
- **テロップ**: 「今朝の先生」「雪の聞き書き」「町の週刊絵本」

### 2:15 AI に任せる所・任せない所（5秒）
- **映す**: 1枚の図（テロップ）。左「Claude: 割り振る・確かめる・相談・絵本」／右「人とプログラム: 得点・安全・夜のルール・**ありがとう**」。
- **ナレ**: 「AI は段取りを。人は、会いに行く。」

### 2:20 作り方の画面＋笑い②（20秒）
- **映す**: スマホの Claude アプリで、日本語で Claude Code に指示している画面の収録（例: 「ホームの隊長を3羽にして」→ 返事「できました」）→ GitHub のコミット一覧を親指でスクロール（日本語のコミット文がずらっと）→ `docs/tasks.md` の `[x]` の列 → **またソファーの実写**。
- **ナレ**: 「学生服の営業をしています。子どもたちに『やってみよう』と話している自分が、40代でやってみました。」「プログラミングは初心者。**コードを書いた時間はゼロ。全部、スマホから日本語で話しかけただけ。** 6日間、ほぼこの姿勢でした。」「パソコンは、この動画を作るために初めて開きました。」
- **テロップ**: 「開発: スマホ100%」「コードを書いた時間: 0分」「PC: この動画の編集のみ」「Claude に『なんなんだよコレ』と声が出た」
- 補足テロップ（1行、小さく）: 「仕様を先に決め、Claude Code をループで自走。企画役と点検役のエージェント。テスト 469本」

### 2:40 イメージ② 見たい未来（12秒）
- **映す**: 理想の朝のイメージ画（Claude に描かせたイラストでも、雪の写真に人を重ねたものでもよい）。マンションの人も、雪かき機を持っている人も、子どもも、一緒に玄関前の雪をどけている。「ありがとう」が行き交う。
- **ナレ**: 「その朝が、マンションの人も、雪かき機を持っている人も、一緒にやるのが当たり前の朝になってほしい。」

### 2:52 締め（8秒）

## 笑いの入れどころ（まとめ）
使うかどうかは本人が選ぶ。多すぎると本気が薄まるので、**3つまで**がおすすめ（★が本命）。

1. ★ 0:15 「思い立ったのは、ソファーの上でした。」（真面目な振り → ダラダラの落ち）
2. ★ 2:20 「コードを書いた時間: 0分」「PC はこの動画の編集だけ」「6日間ほぼこの姿勢」
3. ★ 隊長の語尾「〜しま」「〜えな」に「※語尾はシマエナガです」
4. 「雪かきは、毎日庭に何メートルも穴を掘っているようなもの」（本人の実感。0:00 か 0:15 で）
5. 「夜はよその家に行けません。防犯です。隊長も寝ます。」（19時〜6時のルールを1秒で）
6. 「Claude に『なんなんだよコレ』と声が出た」（2:20）
7. 腰: 「毎年腰を痛めるので、今年は寝たまま作りました」

**実写・画像**
- 雪の朝の通り（実写 or 写真2〜3枚）。
- ソファーの手元（ブランケット・スマホ・飲み物。10秒くらい、2回使う）。

**撮影の前に（demo.md と同じ）**
- 撮影は **日本時間 6:00〜19:00**（夜はよその家の「行く」が断られる）。
- 公開版に ANTHROPIC_API_KEY が入っていて、隊長の文・写真の確認・カードが定型でないこと。
- 隊長の声: 撮影前に `VOICEVOX_API_KEY`（無料の鍵）を入れておくと、続けて鳴らしても機械音に戻らない。

- `/admin` は 0 → 1 → 3 の順。2 は押さない（架空の人に担当が付いて「助けて」が減る）。

## 本人に決めてほしいこと
1. **冒頭の順番**: 案1「雪の静かな朝 → ソファーで落とす」（上の台本）／案2「ソファーから始めて、途中で真面目になる」（つかみは強いが、審査の人に軽く見られる心配）。おすすめは案1。
2. **笑いの濃さ**: 上の7つから使うものを選ぶ（おすすめ★3つ）。
3. **顔を出すか**: 出さない前提。出すなら 2:20 の「自分の話」に数秒。
4. **声のありがとうを吹き込む人**: 家族か知人（架空の家の人の役）。
5. **3羽の写真と未来のイメージ画**: 自分の写真か、Claude に描かせるか。描かせるなら明日の朝イチで用意する。
6. 動画の中でいちばん長く見せる機能を「声のありがとう」にしてよいか（23秒。ここが「Claude の活用」の裏返しの主張でもある）。
