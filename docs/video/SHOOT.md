## 編集の順番（14:45〜16:15・iMovie）

1. **ナレーションを先に置く。** これが時間の芯。3分を超えていたら `script.md`「長すぎたときに削る順」で切る。
2. 実機の収録を台本の時間に合わせて置く（S0 → S12 → S2 → S3 → S4 → S4b → S5 → S6 → S7 → S8 → S9 → S10 → S11 → オチに S1）。足りない所は実写で埋める。
3. 数字の場面（0:19〜0:33）は黒地に白文字の一行＋右下に小さく出典（`script.md` の表）。
4. テロップは大きく、1場面1行まで: 「拠点7、あと3人」「Claude が割り振り」「写真1枚で Claude が確かめる」「ありがとうは、本人の声で」「2026年11月8日 初雪」。

## 逃げ道

- **「行く」が断られる** → 時計が 19 時を過ぎている。昼に撮る。
- **写真の確認で「まだ」と言われる** → 玄関前から道路側を明るく撮り直す。どうしてもなら「それでも完了にする」。
- **「前に送られた写真と同じでした」** → その場で撮り直す（カメラロールの古い写真を選ばない）。
- **声のありがとうが前の声で埋まっている** → 「吹き込み直す」から撮れば同じ流れになる。
- **道の報告が B に届かない** → B の `/solo` のトグルがオンか、ピンが拠点7の近くか、1人1日3回の上限を超えていないか。届かなければ、地図の黄色いピンと A 側の画面だけで切り、ナレーションはそのまま。
- **なかま帳が空** → 「記録」タブか、S10 の日曜の夜の隊長トークだけにする。
- **AI 生成の時間がない** → 0:04 は実写の轍（11）に「北海道の人は、雪にはまった車を、100%助けます」をテロップで。2:14 後半は実写 3（ひとりの後ろ姿）→ タイトルへ。
- **途中でやり直したい** → `/admin` の「0 前夜の予告」で朝をまっさらに（カードは残る）。
- **17:00 を過ぎた** → 18:00 まで提出できる。17:30 には必ず書き出しを始める。
