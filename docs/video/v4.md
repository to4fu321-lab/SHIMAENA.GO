## ひとことで

**語り手を、アプリの中の AI「シマエナ隊長」本人にしました。** 隊長が「ある雪の朝の10分間」を、自分の仕事として報告します。

- 山場は「ありがとう」。隊長は「これだけは、ぼくの仕事ではありません」と言い、**動画の中でも声を合成せず、数秒を空けておきます。**
- そのあとに「つながり」: バトンと、なかま帳。雪かきが、近所の人と顔見知りになる入口になる、という話です。

> **先に知っておいてほしいこと（正直に）**
> 1. **写真 → 完了 → カードの場面だけ、Claude の鍵なしの録画です**（写真の確認とカードの絵は「見本の答え」）。録画に使った作業環境の通信の中継が、30秒をこえる返事を途中で切るため（公開版の不具合ではありません。11/11 に調べて分かりました）、公開版の完了画面を最後まで録れませんでした。動画の中にも小さく書いてあります。
> 2. 公開版の録画は場面ごとに撮り直したので、スマホの中の小さい文字（今朝の雪の名前・拠点の番号）が場面でちがう所があります。
> 3. **町の絵（雪かきをする人たち・雪かきをする人のいない家）と、なかま帳の右の図は、架空のイメージ**です。画面に小さく書いてあります。実写は本人が撮った 11/8 の公園の写真1枚だけです。
> 4. 語りは隊長のことばとして **Claude が書きました**。事実（数字・しくみ・決まり）は README と仕様に合わせています。言い回しを変えたいときは `scripts/video-v4/script.cjs` を直します。
> 5. 録画のあと、公開版は「7:10 の見本の状態」に戻してあります。

## 構成（26場面）

場面の順番: あいさつ → 静かな朝 → 数字（94%・68%）→ きっかけ → 題字 → 登録 → ① 知らせる → ② 割り振る（Claude の理由を拡大）→ 行く → 地図（印をアップ）→ ③ 確かめる → カード → **隊長トーク** → **ソロ** → **バトン** → **なかま帳** → **ありがとう** → 空けておく → 作った人 → 7日間 → 決まり → 一言 → くっつく → 初雪 → **これから（町内会・行政）** → 題字。

ことばの全文は `scripts/video-v4/script.cjs`、正確な時間割は `node scripts/video-v4/layout.cjs` が出します。

## 音

楽器はアプリと同じ `lib/sound/`（Web Audio 合成。音ファイルなし）。あいさつは風だけ → 静かな朝はエレピ → 題字で鈴 → 登録〜割り振るは「しらかばの朝」→ **「行く」の瞬間に「出撃！」** → **完了の瞬間に「灯りがともる」** → 「ありがとう」に向けて消え、**空けておく5秒は風だけ** → 作り方は「出撃！」の刻み → 「人は、会いに行く。」で和音ひとつ → くっつく〜初雪は「灯りがともる」の広がる所 → おわりの和音。全体は -14 LUFS。

## 作り直す

```bash
npm install && npm run build
node scripts/video-v4/make.cjs            # 時間割 → 音楽 → 全コマ → 音 → MP4（約8分）
node scripts/video-v4/make.cjs record     # アプリの画面も録り直す（手元・鍵なしなら見本の答え）
REC_BASE=https://shimaena-go.vercel.app ADMIN_PW=（運営の合言葉） node scripts/video-v4/record.cjs   # 公開版で録る（合言葉はファイルに書かない。終わると見本の状態に戻す）
node scripts/video-v4/make.cjs voice      # 隊長の声も作り直す（先に bash scripts/video-v3/tts/setup.sh）
node scripts/video-v4/make.cjs audio      # 画はそのまま、音だけ入れ替える
```

| 直したいもの | 直すファイル（`scripts/video-v4/`） |
|---|---|
| 隊長のことば・場面の順番・間 | `script.cjs`（秒は書かない。声の長さから時間割になる。179秒を超えると止まる） |
| 声の速さ・調子 | `voice.cjs` |
| カメラ（寄り・引き） | `camera.js`（点 = 秒・中心・倍率） |
| 場面の絵・文字 | `act1-town.js`（町・題字）・`act2-demo.js`（アプリの画面）・`act2b-tsunagu.js`（バトン・なかま帳）・`act3-thanks.js`・`act4-maker.js`・`act5-end.js`。確かめるのは `node scripts/video-v4/render.cjs preview 12.5,40` |
| 音楽の並び・効果音 | `score.cjs` |

声のモデル（まい）は、`bash scripts/video-v3/tts/setup.sh` が一緒に取ってきます。
