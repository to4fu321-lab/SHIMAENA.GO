# 紹介動画 v4「隊長の朝」— ねらい・構成・作り直し方

`docs/video/shimaena-go-taicho.mp4`（1920×1080・30fps・**2分58秒**）。11/10 に、本人の「元の台本などは無視して、表現方法や伝え方など全て Claude の自由にして良いので1から作成して」で作った版です。

## ひとことで

**語り手を、アプリの中の AI「シマエナ隊長」本人にしました。** 隊長が「ある雪の朝の10分間」を、自分の仕事として報告します。

- 声は、アプリの隊長と同じ声（雪降白華）。合成音声が「仮の声」ではなく、**隊長その人の声**になります。
- 山場は「ありがとう」。隊長は「これだけは、ぼくの仕事ではありません」と言い、**動画の中でも声を合成せず、5秒を空けておきます。**（v3 は孫の声を合成で代えていました。v4 は「AI に書かせない」を動画でも守ります）
- 終わりの近くで、この動画の頼まれ方（本人の原文）を画面に出します。「全部自由に」と言われて、隊長が語ることにした、という種あかしです。

> **先に知っておいてほしいこと（正直に）**
> 1. **画面の録画は、Claude の鍵なしで撮っています。** 隊長の理由の文・写真の確認・カードの絵は「見本の答え」です（流れと画面は本物）。動画の中にも小さく書いてあります。`.env.local` に `ANTHROPIC_API_KEY` を入れて `node scripts/video-v4/make.cjs record` で、本物の答えに撮り直せます。
> 2. **町の絵（雪かきをする人たち・掘る人のいない家）は、架空のイメージ**です。画面に「※ 町と人は、架空のイメージです」と出しています。実写は本人が撮った 11/8 の公園の写真1枚だけです。
> 3. 語りは隊長のことばとして **Claude が書きました**（本人の台本 `script.md` は使っていません）。事実（数字・しくみ・決まり）は README と仕様に合わせています。言い回しを変えたいときは `scripts/video-v4/script.cjs` を直します。

## 審査基準との対応

| 審査基準 | この動画で見せている所 |
|---|---|
| インパクト 30% | 「見えない」家を絵で1軒に絞る → 数字2つ → 足りないのは「きっかけ」。終わりは「本物の雪の朝は、これから」と言いすぎない |
| デモ 25% | 0:50〜1:52 は全部、本物のアプリの録画。隊長の3つの仕事（知らせる・割り振る・確かめる）で順に見せ、右上の「10分の時計」が一周する |
| Claude の活用 25% | 語り手が Claude 自身。任せる仕事3つと、任せない決まり3つ。作り方（初心者・スマホ・日本語・7日・点検ループ）。この動画そのものが「全部自由に」で作られたこと |
| 深さと実行力 20% | コミット 354・テスト 572（実数）、流れるコミットの記録は `git log` そのまま。夜の点検ループ |

## 音

楽器はアプリと同じ `lib/sound/`（Web Audio 合成。音ファイルなし）。あいさつは風だけ → 静かな朝はエレピ → 題字で鈴 → 登録〜割り振るは「しらかばの朝」→ **「行く」の瞬間に「出撃！」** → **完了の瞬間に「灯りがともる」** → 「ありがとう」に向けて消え、**空けておく5秒は風だけ** → 作り方は「出撃！」の刻み → 「人は、会いに行く。」で和音ひとつ → くっつく〜初雪は「灯りがともる」の広がる所 → おわりの和音。全体は -14 LUFS。

## 作り直す

```bash
npm install && npm run build
node scripts/video-v4/make.cjs            # 時間割 → 音楽 → 全コマ → 音 → MP4（約8分）
node scripts/video-v4/make.cjs record     # アプリの画面も録り直す
node scripts/video-v4/make.cjs voice      # 隊長の声も作り直す（先に bash scripts/video-v3/tts/setup.sh）
node scripts/video-v4/make.cjs audio      # 画はそのまま、音だけ入れ替える
```

| 直したいもの | 直すファイル（`scripts/video-v4/`） |
|---|---|
| 隊長のことば・場面の順番・間 | `script.cjs`（秒は書かない。声の長さから時間割になる。179秒を超えると止まる） |
| 声の速さ・調子 | `voice.cjs` |
| 場面の絵・文字 | `act1-town.js`（町・題字）・`act2-demo.js`（アプリの画面）・`act3-thanks.js`・`act4-maker.js`・`act5-end.js`。確かめるのは `node scripts/video-v4/render.cjs preview 12.5,40` |
| 音楽の並び・効果音 | `score.cjs` |

隊長の声のモデル（雪降白華）は、`bash scripts/video-v3/tts/setup.sh` が一緒に取ってきます（`download_models.sh` に足しました）。
