## 0. 一言
**「寒い冬は、くっついて乗り切る。」**
雪の朝に LINE で点呼が届き、町内のランダム3チームがひとり暮らしの家の雪をどける。参加するほど、その時だけのカードが増える。

- 対象: 札幌の町内会ひとつ（デモは架空の「しらかば町内」）
- 依頼者: 高齢者。LINE が使えなければ家族が代理登録
- 手伝う側: 若者〜高齢者。子どもは保護者と一緒に偵察・補給で参加
- 既存との違い: お金のマッチング（Snow Bell 等）ではなくチーム戦。年1回のイベント（スポーツ雪かき選手権）ではなく毎朝。健康アプリ（札幌市アルカサル）にない「地図・チーム・ご近所の顔」

## 3. ミッションと小タスク
- 1軒＝1ミッション。Claude がレベルから5分単位の小タスクに分解: 玄関前の通路（5分）／階段の砂まき（5分）／雪捨て場まで1往復（5分）／車庫前（15分）／道路まで（30分）
- 偵察（写真1枚で「ここまだ」）と補給（お茶・カイロ）は常に5分タスクとして存在
- 「一緒なら」と答えた依頼者は必要人数を1減らし、本人の参加も3点

## 4. ヘルプ通知と見守り
- 発火: (a) 開始20分前に人数不足 (b) 現場の「人手が足りない」ボタン (c) 作戦配信後の新しい「いいえ」
- 通知先: 近い順に 300m → 600m → 1km、全チーム。文面に「5分でもOK」の小タスクを添える
- 間に合わなければ「サポーター」（町内会役員役）へ
- 点呼に返事がない依頼者の家は灰色点滅 → 近所に「声かけお願い」→ 家族にも通知
- **体調や医療の判断はしない**

## 6. 地図（ぬりえ）
- Leaflet + OpenStreetMap タイル（出典表記必須）
- 建物の形は OpenStreetMap から事前取得（Overpass API）し、背景として淡く描く
- **塗るのは 50m 四方のマス**（11/2 本人決定）。どの家かは地図に出さず、正確な場所は割り当てられた人の LINE にだけ届ける
- マスの中に複数の家があるとき: 人手不足が1軒でもあれば赤点滅を優先／全部終われば塗る（2チームなら2色目を破線の縁）／途中は終わった割合だけ薄く塗る
- マスの状態色: 白＝未対応／赤の縁取り点滅＝人手不足／チーム色の縁取り＝向かっている／チーム色で塗り＝完了／灰点滅＝返事なし
- 初期表示は徒歩圏（半径約 700m、ズーム16）を画面いっぱい。拡大縮小できる
- 上部: 3チームの得点バーと「今朝の雪HP」（降雪量 × 拠点数、完了で減る）
- 下部: 自分の割り当てと「行く」「終わりました」「人手が足りない」
- 地図に氏名は出さない。拠点は実在の建物と結びつけず、マスと番号だけ

## 7. ありがとうカード
- その朝に動いた人だけが受け取る。**二度と発行しない。発行枚数＝その朝の完了数**
- 載せる: レア度ピル（「早朝の群れ ★★ ・ 32枚限定」）／デザイン名＋英語副題／来た人の名前／日付・チーム／**右上の消印**（町内名・排雪○kg・No.○/○・日付）
- 載せない: お宅の名前。依頼者の一言はカード裏面（LINE では2枚目）
- 絵は **Claude が SVG で描く**（画像生成AIは使わない）。基本は「パステル×ネオン×メンフィス柄のかわいいシティポップ」（`docs/design/cards/01-kawaii-citypop.svg`）。耳あての色＝チーム色、並ぶシマエナガの数＝来た人数
- レアでタッチが変わる: 早朝＝80sレトロウェーブ／大雪＝切り絵／連続5日＝ドット絵／混成＝鈴木英人系（試作は `docs/design/cards/`）
- デザイン名は Claude が状況から毎回つける（例: 玄関までの三十歩 / Thirty Steps to the Door）
- 排雪量は Claude が面積×深さから kg で推定し、身近な換算もつける（軽トラ1台分 など）
- 書き出し: 正方形（Instagram）と 4:5（X）。レアはホログラム風アニメ
- 10枚で町内会からのご褒美（デモでは架空の銭湯券）

## 8. 家族への通知
「今朝、お母さんの家の雪かきが終わりました（写真）」「点呼に返事がありません」「今週は3回手伝ってもらいました」

## 9. Claude の役割（すべて JSON 出力。採点表 `data/rubric.json` を毎回渡す）
1. レベル判定: 登録の2問 → 家のレベル・必要人数・小タスク
2. 司令官: 予報＋点呼回答＋拠点＋チーム人数 → 重要度・割り当て・予告と作戦の文面
3. 写真確認: 雪が除かれているか／通路が通れるか／凍結が残っていないか
4. カード: デザイン名・英語副題・SVG・排雪kgと換算・レア判定
5. 週末: 実況文・称号・翌週のシャッフル案

## 10. メニュー（LINE リッチメニュー）
v1.4 から: **出動する／町の地図／活動カード／使い方** の4つ（設定は Web の `/settings` へ）。くわしくは末尾の v1.4。

## 10.5 あそびかた画面 `/rules`
誰でもすぐ分かる1枚: 手伝う人は3つだけ／手伝ってほしい人は1つだけ／チームと点数／持ちもの／けがをしないために（屋根の下に近づかない・車と除雪車・転倒・腰・ひとりでやらない・無理しない・体調がすぐれない日は休む）。体調の判断はしない

## 11. 技術
Next.js (App Router) + TypeScript + Tailwind／Vercel（Cron: 21:00 予告、6:30 点呼）＋ GitHub Actions（6:40 作戦。Hobby は Cron 2本まで）／Neon（Postgres、素の SQL）／Claude API（画像入力＋JSON）／LINE Messaging API ＋ LIFF／Open-Meteo（無料・キー不要）／Leaflet ＋ OpenStreetMap／SVG→PNG 変換（LINE の画像メッセージ用）

## 12. やらないこと・守ること
- 音声・電話入力／決済／他町内との比較／個人順位／医療・体調の判断
- 実在の氏名・住所・電話番号を入れない。地図に氏名を出さない。位置表示は 50m 単位に丸める

## v1.31 追加（11/7、本人の指示「スマートウォッチ対応したい。雪かきの動き連動とか出来ない？ 時計の機能や利便性を最大限活かして」）

- **手首の点呼（通知のボタン）**: スマホに届く通知は、ペアリングした時計（Apple Watch・Wear OS）に映る。点呼（手伝う側「朝（〜9時）／今日は休む」、お願いする側「はい／いいえ」）と人手が足りない家（「行く（10分でも）／今は無理」）の通知に**ボタンを 2 つ**付け、押すとアプリを開かずに答えが隊長に届き、「✅ 朝（〜9時）を受け付けました」と同じ通知に出る（`lib/push/notice.ts` の `noticeActions`、`public/sw.js`、`/api/push/act`）。誰かはログインの印（cookie）だけで決め、答えられるのはこの 2 種類だけ。ボタンが出るのは Android（Chrome は 2 つまで）。iPhone と Apple Watch は通知にボタンが出ないので、通知を開いて答える（今までどおり）。
- **スコップカウンター（雪かきの動き連動）**: 時計の動きは Web からは読めないので、**ポケットか腕のスマホの加速度センサー**（DeviceMotion）で「ザクッ」を数える（`lib/watch/strokes.ts`・`components/ShovelMeter.tsx`）。しきい値 9 m/s² を超えて 4 m/s² に戻ったら 1 回、前の回から 0.42 秒は数えない（歩く揺れは数えない）。1 回ごとに「ザクッ」の効果音、10 回ごとに振動（Android）、**50 回ごとに「ひと息入れて、腰をのばそう」**（けがをしないための決まった文。体調の判断はしない）。1 分あたりの回数も出す。
  - 出すところ: ソロの現地ミッション（自分の家の雪かき・見回り）の「ミッション中」。スイッチでオン（iPhone はセンサーの許可を毎回タップ、Android は一度オンにしたら次も自動）。数えている間は画面を消さない（Wake Lock）。開き直しても続きから。
  - **記録**: 完了のときに回数を `solo_logs.strokes` に残し、クリア画面の「けっか」に「⛏ スコップ ○回」。**得点・羽・kg には入れない**（どけた雪の kg は今までどおり面積×深さ×雪質）。数えなかった日は何も出さない（0 を出さない）。
- **心拍を見る**: Bluetooth の標準の心拍（Heart Rate Service）を流す時計・バンド（Garmin・Polar・COROS・胸バンドなど。Apple Watch・Pixel Watch・Galaxy Watch は流さない）を、**Chrome（Android）の Web Bluetooth** でつなぎ、ミッション中に「♥ 112」と出す（`lib/watch/heart-rate.ts`・`components/HeartRateChip.tsx`）。**表示だけ。保存しない。しきい値も警告も出さない**（体調や医療の判断はしない、の約束）。iPhone では部品そのものを出さない。
- **設定の「時計」タブ**: この端末で使えるもの（通知のボタン／センサー／心拍）を ✓ で見せ、スコップカウンターと心拍をその場でためせる（`components/WatchSettings.tsx`）。
- **やらないこと**: 時計用のアプリ（watchOS・Wear OS）は作らない（期間中に新規制作できる範囲ではなく、審査の環境でも動かせない）。歩数・睡眠・ヘルスケアのデータは読まない。心拍で休憩や中止を判断しない。
