# シマエナGO 仕様書 v1（11/2 確定）

> このファイルが仕様の正本です。変えるときは本人の了承を取ってから。
> 登場人物・町内名・住所はすべて架空です。

## 0. 一言
**「寒い冬は、くっついて乗り切る。」**
雪の朝に LINE で点呼が届き、町内のランダム3チームがひとり暮らしの家の雪をどける。参加するほど、その朝だけのカードが増える。

- 対象: 札幌の町内会ひとつ（デモは架空の「しらかば町内」）
- 依頼者: 高齢者。LINE が使えなければ家族が代理登録
- 手伝う側: 若者〜高齢者。子どもは保護者と一緒に偵察・補給で参加
- 既存との違い: お金のマッチング（Snow Bell 等）ではなくチーム戦。年1回のイベント（スポーツ雪かき選手権）ではなく毎朝。健康アプリ（札幌市アルカサル）にない「地図・チーム・ご近所の顔」

## 1. 登録（冬の初めに1回、LINE だけ）
| 手順 | 依頼者 | 手伝う側 |
|---|---|---|
| 1 | 友だち追加 → 「どちらですか」ボタン | 同左 |
| 2 | LINE の「位置情報を送る」で自宅を登録 | 同左 |
| 3 | 「一人だといつも何分？」（15／30／60以上／わからない）「どこまで？」（玄関前／車庫前／道路まで） | 「朝は何分動ける？」（15／30／60）「道具はある？」（ある／ない） |
| 4 | Claude が家のレベル（1〜3）を決める | ランダムにチーム配属 |
| 代理 | 家族が「家族の代わりに登録」→ 親の家の位置と2問 → 連携コードで紐づけ | |

## 2. 1日の流れ
| 時刻 | 何が起きるか | 操作 |
|---|---|---|
| 前夜 21:00 | Open-Meteo の予報が基準（翌朝6時までに 5cm 以上）を超えたら、司令官が予告「明朝 6:30 に点呼。予想 12cm。長靴と手袋を」 | なし |
| 6:30 | **エナガ点呼**（1問）。依頼者「今朝、玄関は出られそうですか？」はい／いいえ／一緒なら。手伝う側「今朝、何分動けますか？」0／15／30／60 | 1タップ |
| 6:40 | 司令官が家ごとに重要度と必要人数を決め、チームに割り当てて配信 | なし |
| 6:40〜 | 地図が色づく。足りない家は赤点滅。「行く」で確定 | 1タップ |
| 現地 | 小タスクをこなし、写真1枚で「終わりました」 | 2タップ |
| 完了直後 | Claude が写真を確認 → 得点 → 依頼者と家族に通知 → 手伝った人にカード | なし |
| 日中 | 「いまからやる（5／15／30分）」で近くの小タスクを1件もらえる | 1タップ |
| 日曜 | 「今週の群れ」実況、チーム順位、称号、翌週のチームをシャッフル | なし |
| 雪のない日 | 何も送らない | |

## 3. ミッションと小タスク
- 1軒＝1ミッション。Claude がレベルから5分単位の小タスクに分解: 玄関前の通路（5分）／階段の砂まき（5分）／雪捨て場まで1往復（5分）／車庫前（15分）／道路まで（30分）
- 偵察（写真1枚で「ここまだ」）と補給（お茶・カイロ）は常に5分タスクとして存在
- 「一緒なら」と答えた依頼者は必要人数を1減らし、本人の参加も3点

## 4. ヘルプ通知と見守り
- 発火: (a) 開始20分前に人数不足 (b) 現場の「人手が足りない」ボタン (c) 作戦配信後の新しい「いいえ」
- 通知先: 近い順に 300m → 600m → 1km、全チーム。文面に「5分でもOK」の小タスクを添える
- 間に合わなければ「サポーター」（町内会役員役）へ
- 点呼に返事がない依頼者の家は灰色点滅 → 近所に「声かけお願い」→ 家族にも通知
- **体調や医療の判断はしない**

## 5. 得点とチーム（お金に換えない。町内の中だけ。週＝日〜土）
| 行動 | 点 |
|---|---|
| ミッション完了 | 10 |
| 7:30 までに完了 | +5 |
| 赤点滅の家に駆けつけ（自分の割り当て完了後のみ） | +10 |
| 同じチーム2人以上で1軒 | 各 +5 |
| 2チームが同じ家で合流 | 両チーム +5 |
| 偵察／補給／依頼者本人の参加 | 3 |
| 週の目標（全軒 8:00 までに完了） | チーム全員 +20 |
| 週の出撃日数 | 3日で称号、5日で称号＋レアカード確定 |

- 3チーム、ランダム配属、毎週日曜に Claude がシャッフル（出撃回数・体力・方角でバランス）
- 個人順位は出さない。チーム順位と個人の称号だけ

| チーム | 色 | コード |
|---|---|---|
| サルビア | 青（ブルーサルビア） | `#2F6FE4` |
| マリーゴールド | 橙 | `#FF8A3D` |
| ルピナス | 紫 | `#9B5DE5` |

赤と緑は地図の状態色なのでチーム色に使わない。

## 6. 地図（ぬりえ）
- Leaflet + OpenStreetMap タイル（出典表記必須）
- 建物の形は OpenStreetMap から事前取得（Overpass API）。**完了した家はその建物の形をチーム色で塗る**
- 状態色: 白＝未対応／赤の縁取り点滅＝人手不足／チーム色の縁取り＝向かっている／チーム色で塗り＝完了／灰点滅＝返事なし
- 初期表示は徒歩圏（半径約 700m、ズーム16）を画面いっぱい。拡大縮小できる
- 上部: 3チームの得点バーと「今朝の雪HP」（降雪量 × 拠点数、完了で減る）
- 下部: 自分の割り当てと「行く」「終わりました」「人手が足りない」
- 地図に氏名は出さない。デモ用の拠点は実在の建物の形を借りるが、名前は架空で、地図上は番号だけ

## 7. ありがとうカード
- その朝に動いた人だけが受け取る。**二度と発行しない。発行枚数＝その朝の完了数**
- 載せる: レア度ピル（「早朝の群れ ★★ ・ 32枚限定」）／デザイン名＋英語副題／来た人の名前／日付・チーム／**右上の消印**（町内名・排雪○kg・No.○/○・日付）
- 載せない: お宅の名前。依頼者の一言はカード裏面（LINE では2枚目）
- 絵は **Claude が SVG で描く**（画像生成AIは使わない）。基本は「パステル×ネオン×メンフィス柄のかわいいシティポップ」（`docs/design/cards/01-kawaii-citypop.svg`）。耳あての色＝チーム色、並ぶシマエナガの数＝来た人数
- レアでタッチが変わる: 早朝＝80sレトロウェーブ／大雪＝切り絵／連続5日＝ドット絵／混成＝鈴木英人系（試作は `docs/design/cards/`）
- デザイン名は Claude が状況から毎回つける（例: 玄関までの三十歩 / Thirty Steps to the Door）
- 排雪量は Claude が面積×深さから kg で推定し、身近な換算もつける（軽トラ1台分 など）
- 書き出し: 正方形（Instagram）と 4:5（X）。レアはホログラム風アニメ
- 10枚で町内会からのご褒美（デモでは架空の銭湯券）

## 8. 家族への通知
「今朝、お母さんの家の雪かきが終わりました（写真）」「点呼に返事がありません」「今週は3回手伝ってもらいました」

## 9. Claude の役割（すべて JSON 出力。採点表 `data/rubric.json` を毎回渡す）
1. レベル判定: 登録の2問 → 家のレベル・必要人数・小タスク
2. 司令官: 予報＋点呼回答＋拠点＋チーム人数 → 重要度・割り当て・予告と作戦の文面
3. 写真確認: 雪が除かれているか／通路が通れるか／凍結が残っていないか
4. カード: デザイン名・英語副題・SVG・排雪kgと換算・レア判定
5. 週末: 実況文・称号・翌週のシャッフル案

## 10. メニュー（LINE リッチメニュー）
地図／カード帳／いまからやる／設定（役割と位置の変更）

## 11. 技術
Next.js (App Router) + TypeScript + Tailwind／Vercel（Cron: 21:00 予告、6:30 点呼、6:40 作戦）／Neon（Postgres、素の SQL）／Claude API（画像入力＋JSON）／LINE Messaging API ＋ LIFF／Open-Meteo（無料・キー不要）／Leaflet ＋ OpenStreetMap／SVG→PNG 変換（LINE の画像メッセージ用）

## 12. やらないこと・守ること
- 音声・電話入力／決済／他町内との比較／個人順位／医療・体調の判断
- 実在の氏名・住所・電話番号を入れない。地図に氏名を出さない。位置表示は 50m 単位に丸める

## 13. デモ3分（実機3台）
0:00 シマエナガが身を寄せ合う写真 →「寒い冬は、くっついて乗り切る。」
0:10 6:30、3台が同時に震える。点呼。
0:30 依頼者が「いいえ」を1タップ。2台に「7:00 佐藤さん宅へ」。地図が青と橙に。
1:00 現地。人手不足 → 赤点滅 → ルピナスが駆けつけ → 混成。
1:30 完了写真 → 確認 → 建物が塗られる → 3台に違うカード。消印。
2:00 家族の LINE に「終わりました」。前夜の予告、週末の実況、シャッフル。
2:30 「初心者の私が、スマホから Claude Code に指示するだけで6日で作りました」
2:50 「あなたの町内でも、今年の冬から。」
