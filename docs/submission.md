## 1. プロジェクト名
**シマエナGO** — 寒い冬は、くっついて乗り切る。

## 2. 選択したテーマ（おすすめ: 2）
公式ページの出発点は2つ。
1. 「あなたが一番よく知っていること」から、あなたにしか作れないものを作る。
2. 「多くの人を阻んできた壁を取り払い」、誰もが使えるものに。高齢化や人手不足など日本社会の課題の解決。

**おすすめはテーマ2。** 審査の説明（インパクト）が「これまで届いていなかった具体的な人を想定し、その人を阻んでいた壁を取り除いているか」で、シマエナGO の芯（頼めないひとり暮らしの高齢者 → 事前登録と自動判定で「頼みにくさ」の壁を消す）とそのまま重なる。
テーマ1 を選ぶなら、「15年札幌で雪かきをしてきた人だから見えた『知らない家の雪かきはしない』」を前に出す。動画の冒頭はどちらでも通じる作りにした。

## 3. プロジェクトの説明（500字以内。見出しは仮。フォーマットが分かったら合わせる）

シマエナGO — 寒い冬は、くっついて乗り切る。
【誰の、どんな課題】札幌では65歳以上の5人に1人がひとり暮らし。雪の朝、玄関から出られなくても「手伝って」と頼めない。困ったとき近所を頼れる人は8人に1人。若い人も町に知り合いがいない。根っこは同じ「ひとり」です。
【どう解決】お願いしたい家は冬の初めに一度登録するだけ。10cm積もった朝は自動で近所に届き、町内の3チームが10分単位で向かいます。写真1枚で完了。家の人や離れて暮らす家族が声で「ありがとう」を返し、動いた人にはその時だけのカード。チームは毎週入れ替わるので、知り合いが増えます。
【Claude】Claudeは町の「隊長」。家ごとの人数と担当を決め、写真で完了を確かめ、相談にのり、高齢者の雪かきのコツを若い人に届けます。得点と安全はプログラム、「ありがとう」は人の声のまま。任せる所と任せない所を決めて使いました。
【これから】まず1つの町内会で1シーズン。市の福祉除雪の地域協力員を増やす入口に。15年前に札幌へ移り住んだ学生服メーカーの営業が、スマホからClaude Codeに日本語で指示するだけで作りました。

## 6. Claude Code での開発の感想（下書き・本人のことばから）

Claude に初めて触れたとき「なんなんだよコレ」と声が出ました。プログラミング初心者の私が、スマホの Claude アプリから日本語で話しかけるだけで、1週間でここまで来られた。パソコンでコードを書いた時間はゼロです。
いちばん苦しかったのは、要件定義と土台づくり。仕様を先に文書にして「書いてないことは足さない」と約束したことで、Claude Code をループで自走させられました。企画役と点検役のサブエージェント、4時間ごとの点検ループ。自分が寝ている間も、町の人の報告箱から Claude が直してくれる感覚は新しかった。
一方で、感情を乗せるところまで AI に任せたら、自分がいなくなる気がした。だから「ありがとう」は AI に書かせず、人の声のまま届ける設計にしました。作りながらアイデアが出て、実装して、また出て。この繰り返しを永遠にやれるのが、最高に楽しかったです。
