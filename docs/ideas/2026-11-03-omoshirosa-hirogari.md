## 1. 審査員目線で、いまの弱いところ
1. **既視感**: 「雪かきの助け合い」は、米国の多くの市にある Snow Angels（登録 → 1対1でペア → 24時間以内に除雪）、札幌の福祉除雪、Snow Bell（有償マッチング）と似て見える。毎朝の LINE 安否確認も西尾市・秩父市などにある。シマエナGO の違い（点呼が作戦になる・ランダム3チーム・その朝だけのカード）は揃っているのに、最初の30秒で一枚の画になっていない。
2. **「おっ」が遅い**: 0:10〜1:00 は文面と地図の色だけ。最初の見せ場（カード）が 1:30 まで来ない。
3. **入口が1つ**: LINE 友だち追加 → 位置情報 → 2問。LINE を使わない高齢者は家族代理だけ（60代以上の LINE 利用率は約7割＝3割はまだ入れない）。通りすがり・観光客・子どもは入れない。お願いする側は受け取るだけ（「一緒なら」はある）。
4. **町内の外に出る道が細い**: カードの保存（正方形・4:5）だけ。家族通知は受け取るだけ。締めの「あなたの町内でも」の次の一歩（どう始めるか）がない。
5. **Claude が裏方**: 司令官の判断理由が画面に出ない。審査員には「Claude が決めた」ことが見えにくい。鍵が未投入だと文面も定型のまま。

## 2. 案（12個）
各案: 一言／どう遊ぶか／なぜ効くか／デモ3分のどこで見せるか／Claude の使いどころ／実装の重さ／約束ごととの衝突

### 面白さ

#### A1. 今朝の雪に名前をつける（雪ボス）
- **一言**: 毎朝の雪が「相手」になる。雪HPバーがボスのHPになる。
- **どう遊ぶか**: 前夜 21:00 の予告で、Claude が今夜の雪に名前と二つ名をつける（例: 予想12cm・湿った雪 →「ぼた雪のドンブリ」）。地図の雪HPバーにその名前が出る。全軒終わると「ドンブリ、7:52 討伐」と地図が3チーム色に光り、完了の通知にも一行入る。操作はゼロ。
- **なぜ効くか**: 名前がつくと注意と行動が増える。英国気象庁は嵐に名前をつけ、2025年の嵐 Floris では警報域の 93% が認知し 83% が備えた。ゴールが近いほど人は急ぐ（ゴール勾配効果: カフェのスタンプカードで、残りが少ないほど来店間隔が約20%短くなった）。毎朝ちがう名前＝毎朝開く理由。Duolingo も「毎日の小さな続き」で日次利用を伸ばしている。
- **デモ**: 0:10 の予告「明朝の相手は『ぼた雪のドンブリ』」と、1:30 の完了で「討伐」。
- **Claude**: `lib/claude/announce.ts` の JSON に `name`（8字まで）と `nickname` を足す。採点表に「人名・地名・怖い語は使わない。ひらがな多め」を1行。モックは降雪量と気温から定型名。
- **重さ**: 小（announce の schema に2項目、`MapScreen` の HP ラベル、完了時の一行）。「討伐」を LINE で一斉に送ると人数分プッシュを使うので、地図の演出だけにしてもよい。
- **約束ごと**: 衝突なし。名前は雪の性質からつける（人や家からはつけない）。

#### A2. 司令官の「ひとこと理由」を見せる
- **一言**: Claude の判断を文字で見せる。
- **どう遊ぶか**: 6:40 の作戦に、家ごとに1行の理由（「拠点3は道路まで30分。坂なので2人」）。LINE の文面と、地図の「自分の割り当て」に出す。
- **なぜ効くか**: 審査の「Claude の活用 25%」は、画面に判断が見えて初めて伝わる。いまの司令官の出力は割り当て・1人ずつの文面・まとめだけで、「なぜその人数か」が見えない。
- **デモ**: 0:30 の作戦配信で A の画面をアップ。
- **Claude**: `lib/claude/commander.ts` の missions に `reason`（30字まで）を追加。`sanitizePlan` で長さを切る。モックはレベルと距離から定型文。
- **重さ**: 小。
- **約束ごと**: 理由に体調の話を入れない（採点表に明記）。

### 新しい発想

#### B1. ありがとう点呼（お願いした人が1タップで返す）
- **一言**: 助けられた人が、助けた人に「返す」。
- **どう遊ぶか**: 「終わりました」の通知に3つのボタン（ありがとう／助かりました／お茶どうぞ）。押すと手伝った人の LINE にすぐ届き、カードの裏面（依頼者の一言）にも入る。自由文はなし。高齢者でも1タップ。
- **なぜ効くか**: 感謝を受けると次に手伝う率が 32% → 66% に上がった研究がある（Grant & Gino 2010。理由は「自分が社会的に価値がある」と感じること）。既存の共助アプリは「頼む → 来る → 終わり」で、返す道がない。ここが新しい一点になる。
- **デモ**: 2:00。C（お願いする側）が「ありがとう」を押す → A の端末が震えて「○○さんから: ありがとう」。物語が閉じる。
- **Claude**: 3択とその朝の状況（雪の量・時刻・人数）から、カード裏面の一文に整える（例「7時台に2人で来てくれて、助かりました」）。
- **重さ**: 小（postback 1種、文面2つ、手伝った人へのプッシュ）。カード裏面まで更新するなら中（発行済みカードの裏 SVG を作り直す）。プッシュは家1軒につき来た人数分増える。
- **約束ごと**: 衝突なし。点は付けない（お金・順位に寄せない）。

#### B2. 玄関の黄色い旗（LINE がなくても点呼に参加）
- **一言**: スマホがない家は、旗を出すだけ。
- **どう遊ぶか**: 家族が代理登録するとき「LINE なし・旗で答える」を選ぶ。雪の朝、本人は玄関に黄色い旗（布でも紙でもよい）を出す＝「いいえ（手伝って）」。近所の偵察役（子どもでもよい）が地図でその家の「旗が出ている」を押すと点呼の答えになり、司令官に乗る。
- **なぜ効くか**: 黄色い旗の安否確認は各地の自治会で実績がある（兵庫県佐用町は朝夕の旗で見守り。名古屋市港区の資料では、震災時に8割の世帯が旗で無事を知らせた町内会の例）。札幌には小学生の砂まきボランティアの例もあり、子どもが「偵察」で入れる。
- **デモ**: 0:30 に10秒（偵察役が「旗が出ている」をタップ → 灰色が赤縁に）。入らなければ README に図で。
- **Claude**: 写真で旗を見つける判定（`photo.ts` に分岐）。ボタン方式なら Claude は不要。
- **重さ**: 小（ボタン方式: 代理登録に選択肢1つ、点呼でその人には LINE を送らない、地図にボタン1つ）／中（写真判定まで）。
- **約束ごと**: 衝突なし。地図には家でなくマスだけ。旗は黄色（赤・緑は使わない）。

#### B3. 通りすがり参戦（QR から5分だけ、LINE なし）
- **一言**: 町内の人でなくても、5分の偵察・補給ならできる。
- **どう遊ぶか**: 町内の掲示板に QR。読むとブラウザで「5分だけ手伝う」ページ（呼び名を1つ入れるだけ）。偵察（写真で「ここまだ」）と補給だけを受けられ、写真を送ると「旅のシマエナガ」カード（1枚）が出る。家の中には入らない。正確な住所は渡さない（マスまで）。
- **なぜ効くか**: 助けたい人は外にもいる。新潟の除雪ボランティア団体「スコップ」は登録者の6割が県外。北海道美流渡では留学生の除雪ツアーが若者・子どもの参加を広げた。倶知安の「雪はねツアー」は札幌からの参加者も。入口が軽いほど集まる（Be My Eyes は利用者1人に支援者が約10人）。
- **デモ**: 2:50 の前に5秒（「通りすがりでも」）。本編に入れなくてよい。
- **Claude**: 偵察写真の確認（既存の `photo.ts`）、カードの名前（既存）。
- **重さ**: 中（ゲスト名簿・`/join` ページ・ゲスト用の写真 → 完了。`/map` の流れを流用できる）。
- **約束ごと**: 衝突なし。ゲストには家の位置を 50m マスまでしか渡さない。

### 誰でもカンタンに参加

#### C1. 「補給ならできる」ボタン（点呼の4つ目）
- **一言**: 足腰が弱い人も、子ども連れも、点呼で「できること」を選べる。
- **どう遊ぶか**: 手伝う側の点呼に「補給（お茶・カイロ）ならできる」を足す。司令官がその人を補給の5分タスクに割り当てる。3点とカードが出る（得点表の「補給 3」そのまま）。
- **なぜ効くか**: いまは 0／15／30／60分しかなく、雪かきができない人は「0分」しか押せない。札幌市の資料には「元気なのに福祉除雪を利用している」という声があり、元気な高齢者は「出す側」にも回れる。補給は仕様にすでにある役割なので、入口を1つ足すだけで参加者が増える。
- **デモ**: 0:10 の点呼画面に4つ目のボタンが映る（2秒）。
- **Claude**: 司令官の入力に「補給のみ」を渡すだけ。
- **重さ**: 小（`HelperAnswer` に1種、点呼の文面、司令官の入力と点検、テスト）。
- **約束ごと**: 衝突なし。体調は聞かない（「できること」を選ぶだけ）。

#### C2. ことばの切り替え（英語・やさしい日本語）
- **一言**: 留学生・技能実習生・観光客も、同じ点呼で動ける。
- **どう遊ぶか**: 登録の最初に「ことば」を1問（日本語／English／やさしい日本語）。点呼・作戦・完了の文面がその言語で届く。
- **なぜ効くか**: 美流渡の事例では留学生の参加が若者・子どもの参加も広げた。司令官の文面は Claude が1人ずつ書いているので、言語を渡すだけで翻訳できる。
- **デモ**: 0:30 で B の端末だけ英語の作戦が届く。審査員に「広がり」が一目で分かる。
- **Claude**: 司令官・写真確認・カードの一言に `language` を渡す。固定文面（登録・点呼）は英語とやさしい日本語を人が用意。
- **重さ**: 小（点呼・作戦・完了の主要5文面だけ）／中（登録の会話まで全部）。
- **約束ごと**: 衝突なし。

#### C3. 子どもの雪だるま検定
- **一言**: 子どもは「雪の後片づけ」で参加して、Claude が審査員。
- **どう遊ぶか**: 終わった家の雪山で、子どもが保護者と雪だるまを作って写真を送る。Claude が「雪だるま審査員」として星（1〜3）と一言。補給と同じ3点、カードに雪だるまが1つ増える。
- **なぜ効くか**: 岩手県滝沢市の「雪だるま大作戦」（小中学生の高齢者宅除雪＋雪だるま）、小樽の雪かき選手権は「早さと芸術性」で採点。子どもが入ると親も来る。
- **デモ**: 1:30 の後に10秒。本編に入らなくても README とカードで見せられる。
- **Claude**: 写真を見て星と一言（`photo.ts` に「雪だるま」モード）。
- **重さ**: 中（写真の分岐、得点表に1行、カードの絵に雪だるま）。
- **約束ごと**: 得点表に「雪だるま 3」を足す提案になる。車道のそばでは作らない注意を `/rules` に。

### 広がる力

#### D1. 絵文字グリッドで今朝の結果を共有（Wordle 式）
- **一言**: 文字3行で、家も名前も出さずに自慢できる。
- **どう遊ぶか**: 完了の通知とカードに「コピーして貼れる」3行を添える。地図に「結果をコピー」ボタン。LINE グループや X にそのまま貼れる。例:
  ```
  シマエナGO しらかば町内 12/14 雪12cm
  ⬜🟦🟧🟪🟦⬜🟪🟧
  8/8軒 7:52 討伐 ・ 混成2
  ```
- **なぜ効くか**: Wordle は「答えを明かさない絵文字の格子」が手間なく毎日共有され、世界に広がった。マスの色だけなので家も個人も特定できない。
- **デモ**: 1:30〜2:00 に3秒（A が LINE グループに貼る）。README の見本にもなる。
- **Claude**: 不要（純粋な関数）。頼むなら「今朝の一言」を4行目に。
- **重さ**: 小（文字列を作る関数＋テスト、通知に1行、地図にボタン1つ）。
- **約束ごと**: 衝突なし。チーム順位は出さず「軒数と時刻」だけ。他町内との比較は入れない。

#### D2. ビフォー／アフターの1枚絵
- **一言**: 「雪の壁」→「通れる玄関」を1枚で。
- **どう遊ぶか**: 偵察写真（前）と完了写真（後）を Claude が確認したあと、1枚に並べて（SVG で枠と消印をつけて PNG）カードの3枚目として届ける。
- **なぜ効くか**: #trashtag（2019）は「散らかった場所の前後写真」という単純な型だから世界に広がった（最初の投稿が33万回共有）。雪かきは前後の差が大きく、写真映えする。
- **デモ**: 1:30。
- **Claude**: 写真確認（既存）に「表札・番地・人の顔が写っていたら使わない」を1行足す。
- **重さ**: 中（いま写真は保存していない。Vercel Blob か DB に保存する仕組みが要る）。
- **約束ごと**: 表札・番地が写ったものは出さない（Claude が確認）。家族通知に写真を付けるなら spec 8 の変更。

#### D3. 家族の「応援」ボタン（町の外からの参加）
- **一言**: 東京にいる息子が、母の家の雪かきに「参加」する。
- **どう遊ぶか**: 家族への「終わりました」に「お礼を伝える」ボタン（3択）。手伝った人に「ご家族から: ありがとうございます」が届く。日曜の「今週の群れ」に「遠くの家族からの応援 N 件」。
- **なぜ効くか**: 家族は町内の外にいる＝自然な拡散経路（カードを SNS に貼りたくなるのは家族）。感謝の効果は B1 と同じ研究。家族の代理登録はすでにあるので、入口は作らない。
- **デモ**: 2:00 の家族通知で1タップ。
- **Claude**: 不要（文面は定型）。
- **重さ**: 小（postback 1種、プッシュ1通）。
- **約束ごと**: 衝突なし。

#### D4. 町内キット: 回覧板1枚を Claude が作る（`/start`）
- **一言**: 「あなたの町内でも」の次の一歩を、15秒で。
- **どう遊ぶか**: 町内会の役員が「町内の名前」と「地図の中心」を入れると、Claude が回覧板の文面（やさしい日本語・ふりがな・英語）とあそびかた3行を書き、QR（LINE 友だち追加）付きの A4 を PNG で出す。印刷して回覧板に挟むだけ。
- **なぜ効くか**: 札幌市は町内会加入率の低下と役員の担い手不足を課題にし、デジタル化の手引きを出している。福岡市の自治会は LINE 回覧板で餅つきの参加が例年より100人増、札幌市厚別区の町内会は LINE WORKS の回覧板で役員の作業を半減。「紙の回覧板」はいまも最強の配布路。
- **デモ**: 2:50 の締め「あなたの町内でも、今年の冬から」で、`/start` が回覧板を出す画面を5秒。
- **Claude**: 回覧板の文面（町内名・その土地の雪の特徴を入れる）。
- **重さ**: 小〜中（1ページ、Claude 1本、QR ライブラリ、PNG は既存の resvg を流用）。町内を複数持つ仕組み（別の町内のデータ）は作らない。それは大。
- **約束ごと**: 衝突なし。他町内との比較は入れない。

## 3. おすすめ上位3つの理由と、spec のどこを変える提案になるか

### 1位 A1 今朝の雪に名前をつける（雪ボス）
- **理由**: 面白さと「Claude が見える」を同時に満たす。デモの 0:10 と 1:30 の両方に「おっ」が入る。半日で入り、失敗しても外しやすい。
