## 3. コンセプト v3：「雪番（ゆきばん）」— 電話一本で、ランダムチームが高齢者宅に出撃する雪かき合戦

### 一言
**「朝の雪かきを、町内のランダムチーム戦にする。手伝い合うほど両チームが得をする。」**

### ゲーム設計（本人の回答を反映）
| 要素 | 内容 |
|---|---|
| 守る対象 | **高齢者宅の敷地**（玄関〜道路、車庫前、灯油タンク周り、非常口）。各宅が「拠点」。拠点ごとに Claude が難易度（雪量・雪質・人数目安）を出す |
| チーム | 参加者を **ランダムに3チームに自動編成**（例: ゆきうさぎ組／きつね組／しまふくろう組）。**週ごとに Claude がシャッフル**して戦力を均等化（出撃回数・体力申告・住んでいる方角を見てバランス調整）。毎週新しい顔ぶれと組むので、町内の知り合いが増える＝コミュニティ形成そのもの |
| 基本得点 | 拠点を除雪完了で自チームに得点。朝6時台は **早朝ボーナス**。連続出撃（streak）で個人称号 |
| **共闘ボーナス** | 他チームが担当中の拠点に加勢すると、**両チームに得点**（例: 両方 ×1.5）。奪い合いではなく「加勢したほうが得」な設計。一人で重労働を抱えない |
| 役割 | 🔭偵察（窓から写真1枚で「ここまだ」報告。高齢者・子どもも参加可、得点あり）／⛏️除雪／☕補給（甘酒・お茶・カイロ。高齢者が「助けられる側」だけにならない）。どれも得点になる |
| マップ | 町内の拠点を Leaflet + OSM に表示。未除雪(白)→作業中(チーム色・点滅)→完了(チーム色・ロック)。加勢中は2色の縞 |
| 1日の流れ | 前夜: 司令官が予報を読み「明朝6:00、〇〇さん宅に3名」を各チームに配信 → 朝: 電話/LINEで依頼が追加 → 出撃「行く！」 → 完了写真 → 得点＆ありがとうカード → 週末: 週間結果とシャッフル発表 |
| 報酬 | 得点は町内の中だけで比較。デモでは **架空の地元商店クーポン・町内会「雪番手当」**。将来は自治体ポイント（README に将来構想として） |
| 見守り | 大雪翌日に電話もLINEも反応がない拠点を地図で点滅させ「偵察お願い」。医療判断はしない |

### 依頼を音声で受ける（3経路。AmiVoice は「認識エンジン」として採用）
| 経路 | 仕組み | 可否 | 備考 |
|---|---|---|---|
| ☎️ 固定電話 | Twilio Voice に着信→「どうしましたか」→ 音声を認識（Twilio Gather ja-JP、または録音を **AmiVoice API** に渡す）→ Claude が聞き返しつつ依頼を構造化→ 日本語TTSで復唱→ 町内に配信 | **デモ可** | **日本の電話番号は 2024/4 から法律で本人確認必須**。Twilio は法人限定、Vonage の050も本人確認＋郵送確認で数日〜。6日では確実に取れないため、**デモは Twilio 米国番号に国際電話**（010-1-…）。README に「本番は町内会・自治体名義で日本番号」と明記 |
| 🎤 LINE 音声メッセージ | 高齢者が LINE で **音声メッセージを送るだけ**（m4a）→ サーバで取得→ **AmiVoice API（同期HTTP、MP4/AAC・MP3・WAV 対応、毎月60分無料）**で文字化→ Claude へ | **推奨・主役** | 日本製エンジンで高齢者の話し言葉に強い。LINE を普段使いしている高齢者にとって一番自然 |
| 🎙️ LIFF マイクボタン | 画面のマイク→ブラウザの Web Speech API（無料、ja-JP）→ Claude へ | 保険 | AmiVoice で詰まった時のフォールバック |

**LINE WORKS AiCall（キャッチコール含む）について**: 法人向けで申し込みは問い合わせ制、個人向け提供なし。6日では契約できない。ただし「電話をAIが受けて要件を聞き取る」という体験は Twilio＋AmiVoice＋Claude で自作できるので、デモとしては同等のものを見せられる。
**Claude API は音声を直接受け取れない**ため、どの経路も「文字にしてから Claude」。

### Claude の使いどころ（審査25%）
1. **司令官エージェント**: 予報・依頼・参加表明・体力申告を読み、作戦（誰が・どこに・何時に）とチーム編成（ランダム＋均等化）を決める。ツール呼び出し（天気取得／拠点優先度／配信）を Claude に選ばせる
2. **電話・音声の対話**: 高齢者の言葉（「玄関がもう出られなくて」）を聞き返しながら拠点・状況を確定。採点表付き JSON 出力
3. **共闘判定とバランス調整**: 完了写真と参加者から「誰が加勢したか」を判定し、チーム格差が開いたら翌週のシャッフル案を出す
4. **文章生成**: 前夜ブリーフィング、ありがとうカード（声でも読み上げ）、週間結果の実況
5. **開発側**: Claude Code の **Skills**（LINE Webhook追加／Twilio TwiML／AmiVoice 呼び出しの手順）、**フック**（コミット前に `.env` 混入チェック）、**サブエージェント**（UI と API を並行）。README に「どう使ったか」の節

### 技術スタック
- Next.js (App Router) + TypeScript、Vercel、Neon (Postgres)
- Claude API（`ANTHROPIC_API_KEY`、JSON 出力）
- LINE Messaging API（Webhook・音声メッセージ取得）+ LIFF（地図・得点板・マイク）
- **AmiVoice API**（`AMIVOICE_API_KEY`、同期HTTP）
- Twilio Voice（米国番号、Gather ja-JP / 録音→AmiVoice、日本語TTS）
- Open-Meteo、Leaflet + OpenStreetMap
- 審査員が触れるよう、LIFF 画面はブラウザ単体でも開ける
