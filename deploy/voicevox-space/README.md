# シマエナGO 隊長の声（VOICEVOX ENGINE）

シマエナGO の隊長トークの読み上げに使う [VOICEVOX ENGINE](https://github.com/VOICEVOX/voicevox_engine) を、そのまま動かしているだけの Space です。
声の主は VOICEVOX のキャラクター（各キャラクターの利用規約に従います）。

- 設定の手順: https://github.com/to4fu321-lab/SHIMAENA.GO/blob/main/docs/setup.md
- 動いているか: `https://＜この Space の URL＞/version` を開くと、ENGINE の版が出ます
